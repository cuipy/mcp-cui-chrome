# 001 账号密码管理规范

## 目的

网站和账号越来越多，密码容易记混、忘记，网络不通时也查不到。统一记在一份本地文件里：按平台分段，每个平台下面一条一条列清楚，集中记录，随时可查。

## 文件分工

| 文件 | 内容 | 是否进 git |
| --- | --- | --- |
| `docs/zhishiku/001-账号密码管理规范.md`（本文件） | 只写规范、格式、维护方法，**不写任何真实密码** | 进 git |
| `local/all-security-info.md` | 真实账号密码信息，**明文密码** | 不进 git（`local/` 已在 `.gitignore` 忽略） |

原则：规范可共享，真实密码只在本地私有文件里。

## 记录格式

`local/all-security-info.md` 按平台分段：一个平台一个 `## 平台名` 标题，下面每条信息单独一行，用 `- 字段名：值`。

示例：

```md
## 示例网站

- 登录地址：https://example.com/login
- 账号：user@example.com
- 密码：（略）
- 二步验证：手机短信
- 安全问答：无
- 最后登录：2026-01-01
- 备注：无
```

字段说明（没有的写「无」，不要整行省略）：

- **登录地址**：直接能打开登录页的完整网址。
- **账号**：登录用的邮箱 / 手机号 / 用户名。
- **密码**：当前有效密码。
- **二步验证**：单独一条，写清验证方式，例如 无 / 手机短信 / 邮箱验证码 / Ente Auth 动态码 / 微软 Authenticator。
- **安全问答**：单独一条，写成「问题 = 答案」，例如 你第一只宠物叫什么名字 = daju；没有就写「无」。
- **最后登录**：最近一次成功登录的日期（格式 2026-11-16），登录成功后更新。
- **备注**：只放补充内容，例如试错过的旧密码、账号停用原因、备用邮箱。**二步验证和安全问答不要塞进备注**，各自单独成条。

## 维护规则

1. **新收录**：注册或首次记录一个平台时，在 `local/all-security-info.md` 末尾新起一个 `## 平台名` 段落，按上面字段逐条写。
2. **改密码**：只更新「密码」那一行，旧密码挪到「备注」备查。
3. **二步验证 / 安全问答有变化**：只改各自那一行，别动其它行。
4. **每次成功登录后**：更新「最后登录」那一行。
5. **账号停用 / 换号**：在「备注」里写清日期和原因，不要直接删整段。

## 安全提醒

- `local/all-security-info.md` 是**明文密码**，只在本机使用。
- 该目录已被 `.gitignore` 忽略，**不要**用 `git add -f` 强制提交。
- 不要上传网盘、不要发给别人、不要贴到聊天工具里。
- 有条件的话，优先用系统或第三方的密码管理器，本文件只作备份/离线查询用。
